# Licensing and source provenance

No project code license decision is recorded. No blanket LICENSE is added by packaging. Preserve the existing repository/Lovable provenance; clarify intended code licensing with the project owner before redistribution.

Research metadata/excerpts remain attributed to their original sources, with per-document access/license fields in `kb/data` and canonical source versions. Europe PMC discovery/open-access labels are not a blanket right to redistribute publisher full text. The acquisition slice retains metadata and limited abstract excerpts (<=24 words/source), not complete papers. Candidate claims are pending human review. Preserve DOI/PMID, HTTPS links, passage locators, hashes and source versions when modifying curation. [Coverage](../kb/RESEARCH-COVERAGE.md) documents source limitations.

Synthetic doctor/patient aggregate fixtures are project-generated demonstration data, not real patient data or externally licensed clinical datasets. The earlier external 180-row source panel/generator is not packaged here; do not invent its licensing provenance. Dependency package licenses remain their own; this document is not a dependency-license audit or rights grant.
